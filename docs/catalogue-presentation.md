# Product presentation controls

The three-thumbnail gallery is now restricted to V2 reusable pens, retaining full pen, dial and logo views for the selected colour. Range products, disposable pens and other equipment show only their current main/selected variant photo. Their thumbnail row and detail caption are absent, and saved gallery overrides (including boxed-product art) are ignored without deleting the saved data. The gallery editor is shown only for V2 reusable pens in Admin > Products.

Matching dark/light image controls and editable information panels remain available for every product. Empty saved panels stay hidden. Prepared pairs for the twelve previously missing source photos are documented in `product-theme-artwork.md`. Later custom uploads still need matching artwork.

No product, price, inventory or production CMS writes are required. This code change is for the Lovable-synced `review/light-theme` branch; publishing remains with the owner.
