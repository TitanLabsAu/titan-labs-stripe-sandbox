# Titan Labs Aus

Using these pictures as the overall tone, style and feel for the website.  Im looking to build a website where people can come and buy products.

Titan Labs Aus is the name of my business.

Create me a landing page where people will need to create an account using an email and password.  I would need an email sent to their email of choice to confirm their email before the user profile is confirmed and they can log in.  

Have the email have a confirmation link that brings them back to the log in page.

Once they have logged in they will need to complete a user profile.

First Name
Last Name
