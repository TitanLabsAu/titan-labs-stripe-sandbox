# Catalogue naming and product copy

## Scope
- Standardise all product-listing references as “Catalogue”.
- Make every product-listing label derive from one editable name so future changes propagate site-wide.
- Populate every active product with a concise full description and exactly three short key points.

## Content approach
- Use neutral, research-focused wording.
- Avoid medical claims, treatment promises, dosing advice, or statements of human-use suitability.
- Preserve existing product names, prices, images, variants, and ordering.

## Technical details
- Reuse the existing editable site-content system for the catalogue name.
- Update the existing product description and details fields through one database migration.
- Verify the editable name across navigation, page headings, buttons, footer, and product recommendations.
