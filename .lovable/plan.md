# Product descriptions and key facts

## Scope
- Rewrite the full description for every active catalogue product with brief, product-specific information.
- Replace each product’s key points with exactly three concise, informative facts.
- Match the Retatrutide example’s structure and readability across the catalogue.

## Content approach
- Explain what each compound is, its principal biological target or role, and the main areas in which it is studied.
- Use cautious, factual wording such as “investigational”, “studied”, and “researched” where appropriate.
- Avoid dosing instructions, treatment promises, guaranteed outcomes, and claims of approval or suitability for human use.
- Preserve product names, prices, images, variants, categories, and catalogue ordering.

## Technical details
- Update only the existing Full description and Key points fields for all active products.
- Store exactly three key points per product, formatted as a short heading followed by an explanatory phrase.
- Verify that every active product has a non-empty description and exactly three key points.
